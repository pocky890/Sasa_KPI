# Sasa_KPI — 採購分析報告產生器

讀取採購明細 Excel/CSV，產生 HTML 分析報告（下單量、採購人員達交率、毛利率）。
原本是 n8n workflow，現改為本機執行。

## 使用方式

### 視窗版（Windows exe）
雙擊 `採購分析報告產生器.exe`（見 Releases），選資料檔 → 設定年度 → 產生報告。

### 從原始碼執行
```bash
pip install -r requirements.txt
python app.py                         # 視窗版
python analyze.py "資料.xlsx" -o out  # 命令列版
```
輸出：`採購分析報告.html`、`analysis.json`。

## 資料格式
只計「狀態」= `已確認` 的列。需要的欄位：
狀態、採購日期、標準交貨日期、廠商交貨日期、料件編號、採購供應商、採購人員、品名、
分批採購數量、採購未稅金額、銷售金額(未稅)。
欄位名稱不符時會被視為沒有資料。

## 產品線 / 廠牌
- 產品線 / 交易品項：依序用「品名」產品關鍵字、「子類別名稱」、「類別名稱」辨識歸類；三者都沒有才用料件編號「第一碼 + 第4-6碼」對照 `codebook.json`（由 `data/料號編碼.xlsx` 產生）。
- 品項合併：機架式／直立式伺服器（單、雙、四插槽）、刀鋒型伺服器，以及只靠類別名稱「伺服器」歸出的品項，視為同一項「伺服器」（`codebook.py` 的 `ITEM_ALIASES`，之後要合併其他品項加在這裡）。超融合、伺服器元件、印表機伺服器、郵件伺服器也都併入「伺服器」（軟體類的「超融合軟體」不併入）。
- 報表把產品線與廠牌合併成一張表：每個前五名產品線併列其中下單量最高（占比最高）的已識別廠牌名稱。
- 廠牌：依序在「品名」（括號內文字與「for …」之後不計）、「子類別名稱」、「類別名稱」中找廠牌關鍵字；三者都找不到才用料件編號第7-9碼對照碼表。
- 採購供應商為「鼎華智能系統」「FOUR J」「SAP Ireland Limited」者，依供應商各視為一個產品線／交易品項（`codebook.py` 的 `SUPPLIER_LINES`），不再細分第4-6碼或品名，仍依料件編號第一碼分開排名。
- 廠牌辨識不出時，採購供應商「鼎華智能系統」的品項直接以「鼎華」取代空值（`codebook.py` 的 `SUPPLIER_BRANDS`）。
- 第一碼 T 的品項，採購供應商為群環科技、精技台北、精技台南、精技台中、精技新竹、台灣聯想環、漢碩科技且子類別名稱空白者，歸為「硬體維護」，該產品線不另外列廠牌（`HW_MAINT_SUPPLIERS`、`NO_BRAND_LINES`）。第一碼 H、S 的採購不套用。
- 碼表更新後執行 `python make_codebook.py` 重新產生 `codebook.json`。

## 廠牌成長率（YoY / QoQ / MoM）
- 依料件編號第一碼分別，廠牌辨識同上；以採購未稅金額（依採購日期歸屬）加總，每個第一碼列出當期金額最大的前 5 個廠牌。
- YoY（年增率）與去年同期比較；QoQ（季增率）與上一季比較；MoM（月增率）與上個月比較。
- 基準取「最後一個完整月份」：資料最新日期還沒到該月月底就退一個月，避免未滿月造成增率失真。QoQ 用最後一個完整季度；YoY 為比較年「起始月 ~ 基準月」對基準年同月份（基準年選「無」時不計算）。
- QoQ / MoM 不受月份篩選限制（會用到區間以外的月份）。

## 達交率
- 標準交貨日 − 廠商交貨日 ≥ 0 為達交，< 0 為不達交；月份以標準交貨日期歸屬。
- 每月下單量的「逐月趨勢」另有依料件編號第一碼區分的直列表：類別 H、S、T 由上而下排列（`report.js` 的 `MONTHLY_CATS`），各自呈現下單量、採購未稅金額（千萬）與同期年增率。
- 依料件編號第一碼區分的逐月達交率：類別 T、S、H、Y 由上而下直列在同一張表（要增減類別改 `report.js` 的 `WIDE_CATS`）。
- 各採購人員 × 料件編號第一碼的達交率（以類別為主）：每個第一碼（T、S、H、Y）一個區塊，第一列「全部」為該類別合計，其下由上而下列出各採購人員（欄位同第一碼逐月表，為整個區間合計；採購人員依該類別筆數由多到少）。
- 各採購人員達交率：每位採購人員（點開看）依料件編號第一碼分別，每個第一碼列出筆數最多的前 5 個品項（品項歸類同上，不分類／未歸類不列），另有「全部」總計列。
- 達交採購未稅金額 = 達交明細的採購未稅金額加總；未達交採購未稅金額 = 不達交明細的加總；兩者合計為達交率分母明細的採購未稅金額（已排除資料例外）。
- 廠牌達交率：依料件編號第一碼分別，每個第一碼列出筆數最多的前 5 個廠牌，外加「全部」總計列（廠牌辨識同上）。達交率各表同時呈現下單量、採購未稅金額（千萬，拆成達交與未達交）與同期年增率。
- 金額達交率 = 達交採購未稅金額 ÷（達交 + 未達交採購未稅金額），與件數基準的達交率並列於所有達交率表（全體逐月、依第一碼、各採購人員 × 第一碼、廠牌、各採購人員品項）；一頁重點也列出整體金額達交率。只在 HTML 報表呈現，`analysis.json` 沒有這個欄位。
- 樣本數標示：該期間筆數少於 30 筆（`report.js` 的 `MIN_RATE_LINES`）的達交率與金額達交率，在儲存格後加 †、淡色斜體顯示，不套紅綠字；一頁重點的達交率排名也只計筆數 ≥ 30 者。
- 資料例外：「採購未到貨代號」為 資料不齊-(業務)、訂單暫停-(業務)、客戶因素-(客戶)、其他原因-(其他)、倉庫未收-(倉庫) 者標記為資料例外，不計入所有達交率的分母，報表上另列筆數（`analyze.py` 的 `DELIVERY_EXCEPTIONS`）。

## 下單量 / 採購未稅金額 / 增幅
每月下單量、產品線、前五大交易品項、廠牌成長率，以及達交率與毛利率的各表，都同時呈現下單量、採購未稅金額與增幅：
- 採購未稅金額（含銷售額、成本與變化量）一律以千萬為單位、三位小數；不到 0.001 千萬者顯示「≈0」。
- 報表上不列「下單量占比」「採購金額占比」「金額占比」「廠牌占比」等占比欄；報表已不再有「前五大供應商」表；產品線與品項表只在第一欄右側列「占比最高廠牌」的名稱。
- 增幅 = (比較年 − 基準年同期) ÷ 基準年同期；廠牌成長率另有 QoQ / MoM 金額增幅；毛利率年度表的最後一列為只比較兩年度都有資料月份的「同期增幅」（毛利率為百分點差）。

## 一頁重點
報表最上方依目前篩選條件自動產生（只在 HTML 報表，不寫入 `analysis.json`）：
- 六張 KPI：採購未稅金額（千萬）、下單量、整體達交率、未達交採購未稅金額（千萬）、整體毛利率、毛利率低於去年同月的月份；前四項與基準年同期比較。
- 比較期間為「起始月 ~ 最後一個完整月份」：資料最新日期還沒到月底的月份（例如只有月初幾天）不納入，避免未滿月把增幅拉低；基準年選「無」時只看比較年。
- 重點卡：下單量（增加量最大、下滑最多的前 3 個產品線，跨第一碼；各類別增幅）、達交率（比較年達交率最低的前 3 位採購人員與前 3 個廠牌，只計比較年筆數 ≥ 30，另列低於 70% 的人數／廠牌數）、毛利率。
- 參數在 `report.js` 開頭：`HL_TOP`（每個清單列幾項）、`MIN_RATE_LINES`（達交率最少筆數）、`RATE_LOW` / `RATE_GOOD`（紅字／綠字門檻）。

## 資料品質（第 4 節）
報表最後一節讓讀者自己判斷排名與廠牌分析的可信度（依目前篩選範圍，只在 HTML 報表）：
- 各第一碼的採購明細筆數與金額、未歸類品項（含碼表「不分類」）與未識別廠牌的筆數、占比與金額；占比 ≥ 10%（`report.js` 的 `DQ_WARN`）以紅字標示。未識別廠牌的分母不含「硬體維護」。
- 其他檢查：被排除採購人員的筆數、無法判定達交（缺標準交貨日或廠商交貨日）的筆數、資料例外筆數、採購人員空白筆數、採購未稅金額 ≤ 0 的筆數。

## 報表上的篩選
- 基準年可選「無（不比較）」：只看比較年，所有基準年與增加量／增幅／變化欄位會隱藏，排名改依比較年數值。
- 季度（全年、Q1~Q4）與月份區間互相連動，可自行選任意月份區間；兩個年度共用同一個區間。

## 設定
年度、下單量定義（`lines`/`amount`/`qty`）可在視窗調整；其他參數（波動門檻 `MOM_THRESHOLD`、
前幾名等）在 `analyze.py` 開頭。
